# GameMaker Mobile SDK

A lightweight and high-performance native extension for GameMaker designed to bridge mobile platform capabilities with your game logic.

## What it does

This SDK allows developers to integrate advanced mobile features directly into GameMaker games. It handles the communication between GameMaker Language (GML) and the underlying mobile operating systems (Android and iOS), enabling features that are not natively available in the standard engine.

* **Bridges GML and Native Code:** Safely passes data between your game and native mobile environments using optimized JSON strings.
* **Handles Asynchronous Tasks:** Offloads heavy processing or server communications to the background, preventing game stutters or frame drops.
* **Simplifies Complex APIs:** Converts complex Java, Kotlin, Objective-C, or Swift code into straightforward GML functions.

## What it is used for

You can use this SDK to implement a wide range of mobile-specific functionalities, including:

* **Online Services:** Connecting to custom backend servers for player authentication, cloud saves, and global leaderboards.
* **Hardware Access:** Controlling device hardware such as cameras, Bluetooth devices, and advanced haptic feedback.
* **System Integrations:** Implementing local push notifications, deep linking, and secure keychains/storage.
* **Third-Party Services:** Embedding custom analytical tools, ad networks, or in-app purchase verification systems.
